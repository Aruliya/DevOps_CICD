# Gesture Vocal Enhancer

Use MediaPipe hand tracking to control audio effects.

## Gesture Controls

### Open Palm

Bass boost enabled.

### Hand Removed

Bass boost disabled.

## Local Testing

Open:

```text
index.html
```

or use

```bash
python -m http.server 8080
```

## GitHub Pages

Push to GitHub.

Enable:

Settings → Pages

main branch
